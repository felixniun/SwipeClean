# 预期行为清单（测试图片与真机用例）

配合计划书 13.4 关键安全测试使用。在真机上逐项勾选，结果记录到 `docs/PROGRESS.md`。

## 准备的测试图片（建议 10 张）

| # | 图片特征 | 目的 |
| - | -------- | ---- |
| 1 | 竖图（如 3024×4032） | 竖图完整显示不裁切 |
| 2 | 横图（如 4032×3024） | 横图完整显示 |
| 3 | 正方形 | 居中显示 |
| 4 | 超宽全景图 | aspectFit 后上下留黑边，布局不乱 |
| 5 | 低分辨率小图（如 300×300） | 放大到 4 倍不过度模糊崩溃 |
| 6 | 无拍摄日期的图片（如导入的截图） | 稳定次级排序生效 |
| 7 | iCloud 未下载的图片 | 显示加载状态，失败可重试 |
| 8 | 纯色/单色图 | 便于观察滑动动画方向 |
| 9 | 大文件 HEIC（8MB+） | 加载性能观察 |
| 10 | 屏幕截图 | 复核界面缩略图识别 |

## 手势与方向（每项必须通过）

- [ ] 在第 1 张上左滑 → 显示第 2 张，动画方向与"下一张"一致
- [ ] 右滑 → 返回第 1 张
- [ ] 在第一张右滑 → 无反应（不循环到末尾）
- [ ] 在最后一张左滑 → 无反应（不循环到开头）
- [ ] 上滑 → 仅出现"已加入待删除队列"，照片库实际未变（去系统照片 App 验证）
- [ ] 轻微上移（<100pt）→ 不触发标记
- [ ] 斜向 45° 拖动 → 无任何动作
- [ ] 下滑 → 无任何动作
- [ ] 双指捏合 → 放大，最大 4 倍，最小回到 1
- [ ] 放大后单指拖动 → 只平移照片，**不切换、不标记**（来回拖动多次）
- [ ] 放大后向上快速甩动 → **不标记删除**
- [ ] 切换到下一张 → 缩放复位为 1
- [ ] 快速连续左滑 5 次 → 恰好前进 5 张，不跳张不重复

## 队列与撤销

- [ ] 标记 3 张 → 计数显示"待删除 3"
- [ ] 重复标记同一张 → 计数仍为原值（不重复）
- [ ] 撤销 → 最近一张移出队列，浏览回到该张
- [ ] 撤销后再撤销 → 无反应（同一操作不重复撤销）
- [ ] 杀掉 App 重启 → 进度、当前照片、队列完整恢复

## 复核与删除

- [ ] 复核页显示数量、缩略图；单张"取消标记"生效
- [ ] 队列为空时进入复核 → 空态，无删除按钮
- [ ] 确认删除 → 系统弹确认框 → 同意后照片进入"最近删除"，队列清空
- [ ] 删除前手动在系统照片 App 删掉其中 1 张 → App 重新校验并提示，数量更新
- [ ] 拒绝系统确认框 → App 不显示"删除成功"
- [ ] 复核后点"返回整理" → 系统照片库无任何变化

## 权限

- [ ] 首次启动 → 弹授权框；拒绝 → 显示引导页 + 系统设置入口
- [ ] 设置为"有限访问" → 只显示所选照片；调整选择后列表同步
- [ ] 拒绝状态下尝试删除路径 → 报权限错误，不误报成功
